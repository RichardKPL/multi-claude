Visão geral

O Multi Claude é um aplicativo Windows portátil que abre várias instâncias do Claude Desktop ao mesmo tempo. Cada perfil recebe uma pasta de dados separada, mantendo logins, sessões e configurações isolados.

O programa não possui um servidor próprio, banco remoto ou API de backend. A operação principal acontece localmente no computador do usuário.

Fluxo de login

  1. O usuário clica em Entrar em um perfil.
  2. O Claude é aberto com --user-data-dir=<pasta do perfil>.
  3. O usuário conclui o login no navegador.
  4. O Windows pode abrir um processo curto do Claude com o link claude://.
  5. O Multi Claude observa novos processos, localiza o link, encerra o processo passageiro e entrega o link ao Claude do perfil.
  6. O status passa a ser lido do log do perfil.

Privacidade: o fluxo descrito é local. O projeto não envia login, tokens ou dados de perfil para um servidor próprio.

Arquivos e armazenamento

No modo portátil, a estrutura esperada ao lado do executável é:

Multi-Claude-Portable.exe
perfis.db                 # perfis, idioma e tema (SQLite)
log.txt                   # diagnóstico local
dados/<perfil>/           # dados do Claude de cada perfil
profile_pictures/         # imagens padrão e usuario_*

Os caminhos dos perfis são salvos de forma relativa quando ficam dentro da pasta do aplicativo, permitindo mover a pasta completa.

Processos, Windows e Claude

  • Localiza o Claude Desktop instalado pela Microsoft Store ou pelo instalador tradicional.
  • Inicia instâncias com subprocess.Popen e --user-data-dir.
  • Enumera processos claude.exe e lê suas linhas de comando para descobrir a pasta de dados.
  • Fecha uma instância com taskkill /PID <pid> /T /F quando necessário.
  • Lê o Registro do Windows para restaurar ou registrar o protocolo claude:// em versões antigas.
  • Usa o tema do Windows por meio de AppsUseLightTheme.

O executável não inclui dados pessoais, banco, log ou imagens adicionadas pelo usuário.

Servidor, rede e integrações

O app não tem servidor próprio. As conexões e serviços envolvidos são:

  • Claude Desktop: aplicativo externo executado localmente.
  • Navegador: usado pelo fluxo de login do Claude.
  • GitHub Releases: hospeda o executável e fornece a API pública usada pelo site para mostrar versão e tamanho do download.
  • GitHub Pages: hospeda apenas o site estático em docs/.
  • REST Countries Flags: fornece as imagens das bandeiras do seletor de idiomas, com fallback local.
  • Google Fonts: fornece a fonte Inter no site; o layout continua utilizável sem ela.

Não há banco remoto, autenticação do Multi Claude, painel administrativo ou endpoint de comandos.

Website e publicação

  • docs/index.html é a página principal.
  • docs/locales.js contém os dez catálogos de tradução.
  • docs/site.js troca textos, metadados e capturas conforme o idioma do navegador ou a escolha manual.
  • docs/img/<idioma>/ contém capturas reais do app em cada língua.
  • .github/workflows/pages.yml publica docs/ pelo GitHub Actions quando há alteração em main.
  • Idioma não suportado começa em inglês; imagens ausentes também usam a versão inglesa.
